# 🐉 🎤 Wu-Tang Name Generator

Discover your Wu-Tang Clan name by answering questions about your vibe; then watch as the generator forges your alter ego — from *Iron Panda* 🐼 to *Thunder Fist* ⚡.

---

## ✨ Features
- 🐅 Interactive survey with five personality questions
- 🎧 Randomized Wu-Tang-style name generation
- 💥 Sound effects on button click
- 🎨 Dark NYC graffiti aesthetic with Wu-Tang yellow and street fonts
- 📱 Fully responsive design

---

## 🛠️ Built With
- **HTML5** – structure  
- **CSS3** – styling and responsive design  
- **JavaScript** – interactive logic
- **Google Fonts** – Bebas Neue, Roboto Condensed, Rock Salt

---

## 🎯 How to Play
1. Answer the 5 questions about your spirit animal, movie genre, snack, conflict style, and strength.
2. Click “Generate my name!”
3. A random Wu-Tang-inspired name appears with a sound effect.
4. Reload or tweak your answers to get a new vibe.

---

## 📦 Installation & Setup
1. Clone this repository:
     
  ```bash
  git clone https://github.com/your-username/wu-tang-generator.git
  ```
2. Navigate into the project folder:

  ```bash
  cd wu-tang-generator
  ```
3. Open index.html in your browser.
